# Reward-residual control distillation

This document specifies the first SD3.5 implementation of continuous
reward-residual control distillation.  It is deliberately narrower than a
general mixture-of-flow model: all teachers are LoRA adaptations of the same
base model and every control coordinate has a stable, named meaning.

## Oracle and deployment field

For an ordered set of `K` teachers, let `beta = (beta_1, ..., beta_K)`.  The
distillation oracle is

```text
v*(x, t, c, beta)
  = CFG_gamma[v_base](x, t, c)
  + sum_k beta_k (
      CFG_gamma[v_teacher_k](x, t, c)
      - CFG_gamma[v_base](x, t, c)
    ).
```

The first implementation fixes `gamma=4.5` for the base and every teacher.
This equality is an invariant, not a convenience: it places the oracle in the
shared-branch regime where CFG and affine reward-residual composition commute.
The student is evaluated with external `guidance_scale=1.0`; it predicts the
already-composed field in one forward pass.

`beta` is not normalized.  Negative values reverse a reward direction and
values above one extrapolate beyond the corresponding RL teacher.  For three
teachers, `(1/3, 1/3, 1/3)` reproduces the existing equally averaged teacher
oracle.  Teacher order, names, ranges, base model, and target CFG scale are
checkpoint semantics and cannot be reordered on resume.

## Why guided trajectories

Forward-noised data and reverse trajectories produced by a guided field occupy
different state distributions.  Following Adapter Guidance Distillation
(AGD), training states are generated by the oracle itself:

1. sample a prompt, seed, and stratified control vector;
2. start from the normal scheduler noise;
3. evaluate the base and all teacher LoRAs sequentially at the same state;
4. compose the FP32 oracle velocity and advance the scheduler;
5. cache each visited latent and oracle velocity;
6. update the student against the cached target without re-running teachers.

Collection costs `O(K+1)` model forwards per denoising point (and two branches
inside each explicit CFG forward).  Deployment costs one student forward.

## Control conditioning

SD3.5 already maps timestep and pooled text embeddings to the `temb` consumed
by every AdaLN block.  Each named reward coordinate is encoded with a
sinusoidal/Fourier projection and an MLP:

```text
temb_controlled
  = temb_time+text
  + sum_k (E_k(beta_k) - E_k(0)).
```

Subtracting `E_k(0)` makes the control branch exactly zero at the origin for
all parameter values.  The final projections are also zero-initialized, so an
extended checkpoint starts from the stock SD3.5 embedding path.  The base
transformer remains frozen; the student LoRA and the control embedders are
trainable.  Control modules are part of the transformer and are persisted with
PEFT `modules_to_save`, so DDP/FSDP, EMA, and resume use the normal model
checkpoint machinery.

## Identifiability and control sampling

Uniform sampling in a high-dimensional box can let errors from different
teacher directions compensate.  The control sampler therefore mixes:

- `anchor`: all coordinates are zero;
- `axis`: exactly one coordinate is sampled;
- `sparse_joint`: a random non-empty proper subset is sampled;
- `dense_joint`: every coordinate is sampled.

This supplies direct supervision for each basis direction while still learning
compositions.  The sampler is deterministic for `(seed, epoch, process_index,
batch_index)`.  It validates finite ranges containing zero and never silently
clips a value.

The primary loss is FP32 pseudo-Huber on the composed velocity.  Optional
`dt_squared` weighting matches the local Euler transition error.  Positive and
negative teacher branches are retained for diagnostics, but PDM is not the
training objective in this fixed-CFG release: the deployment target is one
composed field.  A future model that exposes CFG itself as another learned
control should add branch-aware supervision.

## Configuration and checkpoint ABI

`train.trainer_type` is `reward-guidance-distill`.  Required fields include:

- an ordered, non-empty `teachers` list with unique names;
- `control_ranges`, keyed exactly by teacher name;
- `target_guidance_scale` (shared by base and teachers);
- a stratified control sampling probability map summing to one.

Version 1 is restricted to SD3.5, LoRA, and ODE sampling.  It rejects
per-teacher CFG overrides that differ from `target_guidance_scale`, external
student CFG above one, non-finite controls, missing negative prompt embeddings
for the oracle, and checkpoint manifests with a different ordered teacher
axis.

The checkpoint contains the normal PEFT adapter weights (including the control
module through `modules_to_save`) plus `reward_control_manifest.json`.  The
manifest records the protocol version, ordered controls, ranges, base model,
embedding architecture, target CFG scale, and student inference CFG scale.

## Evaluation protocol

Use matched prompt, initial noise, scheduler, and seed to compare:

- explicit base/teacher oracle;
- distilled one-pass student;
- `beta=0`;
- every teacher axis;
- equal-average combinations;
- negative and extrapolating controls.

Record velocity RMS error by timestep, cosine similarity of each teacher
residual, generated images, and the relevant GenEval/OCR/PickScore metrics.

## Method selection

- Guided Distillation (Meng et al.) and LCM motivate continuous Fourier
  guidance inputs.
- Plug-and-Play Diffusion Distillation and AGD motivate freezing the base and
  training lightweight residual capacity.
- AGD's guided-trajectory result directly addresses the train/inference state
  mismatch and is the main trajectory choice here.
- DICE changes text representations and does not preserve independent reward
  axes.
- Model Guidance and Guidance-Free Training learn from the data/noise objective
  rather than an explicit set of LoRA teacher fields.
- Multi-reward gradient balancing methods address competing reward gradients;
  this trainer instead has an exact affine vector-field target, so it keeps
  those methods as diagnostics rather than replacing the oracle.
